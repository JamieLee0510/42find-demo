# 固定语料 — 召回率与延迟的地基

> **人手写、定标准**（`.42cog/cog.md`：语料与黄金查询集由人产生）。AI 只出初稿，标准归人。
> **每一处命中都必须人工可数、可逐条核对**——这是它小的理由，不是它简陋的理由。

## 为什么不是 exp001 那四份

`docs/experiments/exp001-rg-baseline-cjk/corpus/` 是**那次实验的事实记录**（铁律 5，不改不搬）。
这里是**长期标准**，另起一份，覆盖面更宽。两者角色不同，不是副本关系。

## 每份覆盖什么

| 文件 | 覆盖的坑 | 为什么要它 |
|---|---|---|
| `01-simplified.txt` | 简体 | 与 02 配对，验簡繁互查 |
| `02-traditional.txt` | 繁体 | 与 01 同义、异形——查任一边都该命中两边 |
| `03-width.txt` | 全角 / 半角 / 同行混排 | 验全半角归一，且混排一行防「行级巧合」 |
| `04-one-to-many.txt` | **繁简一对多**（发 → 發 / 髮） | **非对称展开的钉子**：查「发」该中三处，查「發」**不该**中「髮」 |
| `05-variant.txt` | 异体字（户 / 戶） | exp001「未测」列出的坑之一 |
| `06-inline.txt` | 词夹在句中、无空格 | exp001 已证 rg 过关；留作**回归护栏**，防归一层把它弄坏 |
| `07-outside-table.txt` | **表外字符**（纯 ASCII / 数字 / 假名） | 验表外字符原样匹配——不报错、不静默丢弃 |

## 边界

- 规模只够验**行为对错**，**不足以证明任何性能结论**。延迟数字只作同语料前后对比，不作绝对声明。
- 日文假名在 `07` 里**只作表外字符**出现，本刀不做假名归一（见 issue #4 范围外）。
- 改这里的任何一个字节，`../queries.tsv` 的期望值**必须重新过人眼**——
  `.42cog/cog.md` 已写死这条：三件不同步，召回率就是假的。
