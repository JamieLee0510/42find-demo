## 一、它们做到的

逐项核对

四态判定，不许用「基本满足」这种含糊说法。

| # | 不可妥协的那条 | 状态 | 差距是什么 | 修起来要什么 | 分级 |
|---|---|---|---|---|---|
| 1 | | 已实现 / 部分（缺什么）/ 完全没有 / 偏离 | | 接一根线 / 得从头造 | P0 / P1 / P2 / P3 |
| 2 | | | | | |
| 3 | | | | | |

**「修起来要什么」这一栏最要紧。** 同样是「缺」，成本差一个数量级：

| 缺法 | 成本 |
|---|---|
| **能力已经有了，只是没接上** | 低成本高收益，优先做 |
| **能力本身就没有** | 要立项，另算 |

判「缺」的时候多走一步，去底层看看是哪一种。

## 二、它们没做的

| 找过什么 | 结论 | 是哪一种 |
|---|---|---|
| | **无人涉足** ／ 有但不适用（说明为什么） | 没顾上做 ／ 做不到 |

⚠️ **空白是结论，不是失败。**

⚠️ **同样是「没有」，意义相反**：

| | 意味着 | 怎么认出来 |
|---|---|---|
| **没顾上做** | 可能是机会——他们没空，你有 | 从来没人提过、也没人试过 |
| **做不到** | 可能是天堑——多少人试过都撞回来了 | 提交历史里试过又回滚、issue 里讨论过又关掉 |

**空白不都是机会，有些空白是别人替你踩过的坑。**

### 该不该自己跑一个

| 判据 | 结论 |
|---|---|
| 搜一下就有答案 | **不用跑**，去查 |
| 别人做过，只是我没找到 | **先去找** |
| **这道难题多年没解决** | **跑它**——不可能今天拍脑袋解决 |
| 输出清楚，却不知道拿什么喂它 | **跑它**——输入不清楚，正是实验的场合 |

要跑就去 `docs/experiments/` 开一个 `expNNN-<slug>/`：**假设 → 做法 → 结论 → 改变了哪一个取舍**。
**没改变取舍的实验，不值得跑第二个。**
